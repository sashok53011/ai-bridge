# AI Bridge — простая инструкция

AI Bridge — это небольшая программа, которая работает на вашем
компьютере. Она даёт вашим приложениям **один адрес**, через который
они общаются с разными ИИ-провайдерами (OpenAI, Groq, Ollama и другими).
Вы один раз вводите ключи API, а AI Bridge сам выбирает нужный и
пересылает запрос.

Программистом быть не нужно. Всё управляется через простую веб-страницу
в браузере.

## Что нужно

- Компьютер с Windows, macOS или Linux.
- Интернет (только для скачивания и облачных провайдеров).
- Ключ API хотя бы от одного ИИ-провайдера (OpenAI, Groq, …). Локальные
  модели (Ollama) ключ не требуют.

## Быстрый старт (3 шага)

### 1. Установка

Скачайте проект и откройте терминал в его папке:

```
uv sync
```

Это установит всё необходимое. Компилятор и сборка не нужны.

### 2. Один раз войти

Создайте аккаунт на сервере каталога, затем впишите логин и пароль в
программу. Проще всего — задать две переменные окружения (пример для
PowerShell):

```
$env:AI_BRIDGE_EMAIL = "you@example.com"
$env:AI_BRIDGE_PASSWORD = "ваш-пароль"
```

Или скопируйте `config.example.toml` в `config.toml` и заполните строки
`email` и `password`.

### 3. Запустить службу

```
uv run python app.py --serve
```

Откроется веб-страница по адресу `http://127.0.0.1:8080/`. Это ваш
пульт управления.

## Подключить приложение

Ваши приложения (клиенты ChatGPT, плагины IDE, скрипты) обращаются к
AI Bridge, а не напрямую к провайдеру. Дайте им:

- **Адрес:** `http://127.0.0.1:8080/v1`
- **Токен:** выполните `uv run python app.py --token` и скопируйте
  значение.

Токен — это как пароль от вашей локальной службы, храните его в секрете.

Дальше пользуйтесь приложением как обычно. AI Bridge пересылает каждый
запрос лучшему доступному провайдеру и сам переключается, если один
отказал.

## Пульт управления (веб-страница)

Откройте `http://127.0.0.1:8080/` в браузере и войдите. Вы увидите:

- **Каталог** — все провайдеры. Включать/выключать, добавлять свои
  (Ollama на другом ПК, LM Studio и т. д.).
- **Ключи** — ввод ключа API провайдера. Он остаётся на вашем устройстве;
  страница показывает только «задан / не задан».
- **Проверка** — проверить провайдера и убедиться, что он отвечает.
- **Статистика** — сколько запросов сделали, сколько токенов потратили,
  какая модель ответила.
- **Журнал** (только админ) — лог каждого запроса с телами запроса и
  ответа (по умолчанию свёрнуты, раскрываются по клику).

## Безопасность

- Ваши ключи API хранятся **в зашифрованном виде на вашем устройстве**.
  На сервер каталога они не отправляются.
- Локальная служба требует токен на каждый запрос. На своём компьютере
  это происходит автоматически; через интернет нужен HTTPS или VPN
  (рекомендуется Tailscale).
- Не делитесь токеном. Относитесь к нему как к паролю.
