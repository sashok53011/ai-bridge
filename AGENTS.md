# AGENTS.md

Краткие правила для агентов. О продукте и сервере — [CONTEXT.md](CONTEXT.md)
(читать целиком перед работой), о запуске и деплое — [README.md](README.md).

## Команды

- `uv sync` — зависимости (httpx, cryptography; dev: pytest). Python >= 3.11.
- `uv run pytest` — все тесты: ≈250 шт., ~20 с, **полностью офлайн**
  (сеть замокана через `httpx.MockTransport`).
- `uv run pytest tests/test_catalogue.py` — один файл;
  `uv run pytest -k reconcile` — по имени.
- Линтера, форматтера и typecheck в проекте **нет** — не запускать
  и не добавлять без явного запроса.
- `uv run python app.py ...` требует входа: `AI_BRIDGE_EMAIL` и
  `AI_BRIDGE_PASSWORD` (или поля в `config.toml`) — иначе жалуется сразу.

## Структура

- `core/` — чистые функции «данные → данные»: ни сети, ни файлов, ни
  времени (жёсткое правило, CONTEXT.md §11). Новое состояние — в
  `storage/`, всё сокетное — в `providers/` и `service/`.
- `providers/client.py` — три роли в одном файле: клиент PocketBase,
  HTTP-клиент провайдера, прокси чата.
- `service/ops.py` — действия приставки, которыми делятся CLI (`app.py`)
  и страница (`service/webui.py`); новую логику добавлять сюда, не в `app.py`.
- Состояние приложения — `~/.ai-bridge/` (у хозяина — ключи, токен,
  снапшот; у остальных людей — `users/<id>/`); тесты изолируют себя
  переменной `AI_BRIDGE_HOME`.
- `storage/secretbox.py` — шифрование keys.json (AES-256-GCM, мастер-ключ
  в `master.key`, на Windows — DPAPI). Сломанный/чужой мастер-ключ даёт
  громкий `SecretBoxError` — не «чинить» его молчаливой пересоздачей.
- Аккаунты: чистая логика — `core/accounts.py`; хранилища —
  `storage/{sessions,usertokens,users}.py`; вход и роли — `service/webui.py`
  (страница требует входа всегда; аварийный токен = админ); гейтвей
  персональный: токен человека → его ключи и переключатели.
- Реестр доступа: `client.access_state` (зарегистрирован/заблокирован) +
  `gateway.authorize` (кэш 5 мин, пауза при поломке 60 с); админ блокирует
  кнопкой на странице «Пользователи». URL провайдеров на страницах не
  показываются — только в формах админа.

## Конфиг и окружение

- Приоритет: переменная окружения поверх `config.toml`
  (файл рядом с `app.py`, лежит в `.gitignore`).
- `AI_BRIDGE_SERVER` — адрес каталога, `AI_BRIDGE_HOME` — где хранить
  состояние, `AI_BRIDGE_TOKEN` — токен приставки.
- `config.example.toml` — шаблон с плейсхолдерами; **реальные логин и
  пароль туда не вписывать**, файл отслеживается git.
- Секреты не цитировать в чате, ответах и логах — называть только путь
  к файлу; значения пользователь вводит сам.

## Сервер PocketBase — ловушки

- Вход: клиент пробует коллекцию `users`, затем `_superusers`;
  HTTP 400 от `users` для админ-аккаунта — норма, не баг.
- PUT `/api/ai-config` от суперпользо­вателя заменяет каталог целиком;
  флаги `enabled` ему отправлять нельзя — они живут только на устройстве.
- В отказах сервера важнее статуса — `message` из тела ответа.

## Тесты

- Найдя баг: сначала воспроизводящий тест на данных из логов, потом фикс;
  тест остаётся как регрессия (CONTEXT.md §11.2).
- `service/gateway.py` и `service/webui.py` тестируются поднятием
  настоящего сервера на эфемерном порту — шаблон в `tests/test_gateway.py`
  (`_Harness`).
